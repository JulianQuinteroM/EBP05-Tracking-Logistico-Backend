## EBP05-Tracking-Logistico-Backend

#Sistema de Tracking Logístico - Backend

Este repositorio contiene el backend del proyecto Sistema de Tracking Logístico tipo FedEx, desarrollado como parte de un proyecto académico.

El objetivo del sistema es permitir el registro, seguimiento y consulta del ciclo de vida de los envíos dentro de una red logística, facilitando la trazabilidad de los paquetes desde su registro hasta la entrega final.
